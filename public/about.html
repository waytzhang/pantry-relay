About this demo

Pantry Relay is a local household coordination prototype built with AI assistance for review as an Amazon Alexa+ hackathon candidate. It is not a certified Alexa skill or an Amazon product.

The browser command demo uses a deterministic parser and recipe planner, not a hosted language model. A separate working MCP service exposes the same pantry workflow to compatible agent clients over Streamable HTTP using MCP protocol 2025-11-25.

All seeded household records are fictional. There is no paid API, cloud account, wallet, purchase action, advertising or external email integration. Pantry data stays in the local SQLite database. This prototype supports one household and binds only to the local computer.

Recipes are original demonstration content, not dietary or medical advice. Date labels are organization aids and do not establish that food is safe to eat.
